# LiveGuarder1026

Windows開発版。

## 画面
- 左：コメント（縦約2）
- 左下：警告・検出（縦約1）
- 右：設定・YouTube・AI・統計
- 各欄に独立スクロールバー
- コメントは新しいものを下へ追加し、監視中は末尾を表示
- 警告は新しいものを上へ追加
- 「左だけ表示（最小 約1/3幅×1/2高）」でコメント＋警告を画面いっぱいに表示

## 安全設定
- 起動時：警告のみ
- AI：ON（AIサービス未接続）
- YouTube実操作：OFF
- コメント/警告ログ：3日
- オートタイムアウト記録：削除対象外
- 配布前：記録を全削除ボタンあり

## 起動
1. token.json をこのフォルダに置く
2. py -m pip install -r requirements.txt
3. py LiveGuarder1026.py

※ token.json や認証情報は他人に渡さないでください。
